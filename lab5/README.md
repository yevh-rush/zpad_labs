## Опис завдання
Цей проєкт присвячений створенню інтерактивного веб-додатку за допомогою бібліотеки `Streamlit`. Головна мета — забезпечити зручний обмін результатами дослідження та надати користувачам графічний інтерфейс для початкового аналізу даних вегетаційних індексів (VCI, TCI, VHI).

**Основний функціонал додатку:**
* Вибір часового ряду (VCI, TCI, VHI) та області для аналізу за допомогою випадаючих списків (dropdown).
* Фільтрація даних за інтервалом тижнів та років за допомогою повзунків (slider).
* Кнопка (button) для скидання всіх фільтрів і повернення до початкового стану.
* Три вкладки (tabs) для відображення:
  1. Таблиці з відфільтрованими даними.
  2. Лінійного графіка динаміки обраного індексу за вибраний період.
  3. Графіка порівняння значень обраного індексу для вибраної області з усіма іншими областями.
* Два чекбокси (checkbox) для сортування даних за зростанням або спаданням.
* Двоколонковий макет: інтерактивні елементи керування розміщені в одній колонці, а графіки з таблицею — в іншій.

## Вимоги до системи
* **Операційна система:** Windows, macOS, або Linux.
* **Інтерпретатор:** Python версії 3.9 або вище.
* **Бібліотеки:** `streamlit`, `pandas`, `plotly`.

## Налаштування середовища та встановлення залежностей
Для коректної роботи додатку ізолюйте залежності за допомогою віртуального середовища. 

1. **Створіть віртуальне середовище:**
   ```bash
   python3 -m venv venv
    ```

2.  **Активація середовища:**
    * Для Linux/macOS: `source venv/bin/activate`
    * Для Windows: `venv\Scripts\activate`

3.  **Встановлення бібліотек:**
    ```bash
    pip install streamlit pandas matplotlib
    ```
    *(Або скористайтеся файлом requirements.txt: `pip install -r requirements.txt`)*

## Інструкція для запуску
Для запуску веб-додатку виконайте команду у терміналі:

```bash
streamlit run lab5.py
```
