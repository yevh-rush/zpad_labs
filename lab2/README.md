# Лабораторна робота 2

## Тема
Наука про дані: підготовчий етап

## Мета роботи
Ознайомитись з інструментами підготовки та аналізу даних у Python.
Навчитись працювати з віртуальним середовищем, Jupyter Notebook та бібліотекою pandas,
а також виконувати очищення та аналіз даних.

## Частина 1

1. Створити віртуальне середовище (venv) для роботи з проєктом.
2. Завантажити за допомогою urllib тестові структуровані файли з даними VHI-індексу
   для адміністративних одиниць України.
3. Зберегти файли з додаванням дати та часу завантаження у назву файлу.
4. Реалізувати механізм, що запобігає повторному завантаженню тих самих даних.
5. Зчитати завантажені файли у pandas DataFrame.
6. Виконати очищення даних (data cleaning):
   - видалити зайві стовпці
   - прибрати зайвий текст
   - обробити пропущені значення.
7. Додати до таблиці стовпці з назвою та індексом області.
8. Змінити індексацію областей відповідно до українського алфавіту.
9. Реалізувати функції для формування вибірок:
   - ряд VHI для області за вказаний рік
   - ряд VHI за діапазон років для вибраних областей
   - пошук мінімального та максимального значення
   - обчислення середнього значення та медіани.

## Частина 2

1. Завантажити датасет:
Individual Household Electric Power Consumption Dataset.

2. Відкрити датасет та виконати очищення даних.

3. Реалізувати функції для формування вибірок:
   - записи, де активна потужність більше 5 кВт
   - записи, де сила струму знаходиться в межах 19–20 А
   - випадкову вибірку з 500000 записів без повторів
   - записи, де після 18:00 споживання перевищує 6 кВт.

4. Обчислити середні значення для груп споживання електроенергії.

5. Виконати:
   - нормалізацію даних
   - стандартизацію даних.

6. Обчислити коефіцієнти кореляції:
   - Пірсона
   - Спірмена.

7. Виконати One Hot Encoding для категоріального атрибута.
