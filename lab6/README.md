## Опис завдання
Програма читає відео з камери, відображає кадр у вікні та реагує на натискання клавіш і миші. Для зображення доступні режими обробки, перемикання режимів виконується з клавіатури. Додатково реалізовано малювання мишкою, переміщення хрестика стрілками та зміна яскравості через повзунок.

## Вимоги
- ОС: Linux або інша система з підтримкою OpenCV HighGUI
- Компилятор: GCC 11+ або Clang 14+
- CMake: 3.20+
- OpenCV: 4.x
- Наявність вебкамери або іншого відеопристрою, доступного через `cv::VideoCapture`

## Залежності Збірка та запуск
Перед збіркою встановіть залежності, у репозиторії scripts виконайте:
```bash
chmod +x *.sh
```
```bash
./preinstall.sh
```

```bash
./build.sh
```

```bash
./run.sh
```

Можна передати номер камери як аргумент:
```bash
./run.sh 1
```

## Керування
- `1` - оригінал
- `2` - інверсія
- `3` - Gaussian blur
- `4` - Canny
- `5` - Sobel
- `6` - бінаризація
- `7` - glitch effect
- `r` - скинути малювання
- `space` - пауза
- `c` - очистити сліди миші
- `ESC` - вихід
- Стрілки або `WASD` - рух хрестика
- Колесо миші - зум
- Ліва кнопка миші - малювання ліній
- Права кнопка миші - малювання прямокутників

## Структура
- `src/` - файли реалізації
- `include/` - заголовки
- `scripts/` - службові скрипти
- `CMakeLists.txt` - конфігурація збірки
