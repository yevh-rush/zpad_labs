## Опис завдання
Програма читає відео з камери, відображає його у вікні та має новий режим `F` для детекції облич на базі ResNet-10 (`cv::dnn`). Детекція виконується в основному потоці, тому під час роботи режиму можливі просадки FPS.

## Архітектура
- `CameraProvider` — відкриває камеру та повертає кадр.
- `KeyProcessor` — обробляє натискання клавіш і перемикає режими.
- `FrameProcessor` — застосовує фільтри, малює HUD, хрестик та рамки облич.
- `FaceDetector` — завантажує нейромережу `cv::dnn::readNetFromCaffe` та виконує детекцію в основному потоці.
- `Display` — виводить кадр у вікно.
- `main()` — об'єднує всі класи та запускає головний цикл.

## Вимоги
- ОС: Linux / Ubuntu 22.04+.
- Компилятор: GCC 11+ або Clang.
- CMake: 3.20+.
- OpenCV 4.x з підтримкою `dnn`, `highgui`, `videoio`.

## Керування
- `1` — оригінал
- `2` — інверсія
- `3` — Gaussian blur
- `4` — Canny
- `5` — Sobel
- `6` — бінаризація
- `7` — glitch effect
- `F` — face detection
- `WASD` або стрілки — рух хрестика
- Колесо миші — зум
- ЛКМ — малювання ліній
- ПКМ — малювання прямокутників
- `Space` — пауза
- `R` / `C` — очистити малювання
- `ESC` / `Q` — вихід

## Структура
- `src/` — реалізація
- `include/` — заголовки
- `scripts/` — скрипти встановлення, збірки та запуску
- `models/` — завантажені моделі
